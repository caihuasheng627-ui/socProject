# 双轨收尾设计

## 目标

库存页、组合诊断和模型实验室统一使用当前线上预测契约，同时保留 2019-2023 历史公平比较。两套数据不合并、不横向伪比较。

## 轨道一：历史公平比较

- 数据：Steam 2019-2023 canonical test。
- 模型：LSTM-C、LSTM-D、旧 Hybrid、RF、LightGBM、XGBoost。
- 保留现有统一覆盖、历史回测和逐日误差产物。
- UI 明确标记为“历史公平比较”，不得称为当前线上效果。

## 轨道二：当前线上模型

- 数据：SQLite 最近 180 天面板的独立时间留出集。
- 模型：LSTM-C、LSTM-D、Hybrid V2 Raw、Hybrid V2 Calibrated。
- 评估复用线上价格锚点、价格层级重基准、平滑和上下界校准。
- 单独输出预测 CSV、比较 JSON、回测结果和净值曲线。
- Keras 30 天趋势单独展示，不和 7 天指标混成一个排名。
- API 返回数据范围、饰品数、决策数、模型版本和数据来源。

## 库存价值曲线

- 历史线继续使用数据库真实价格聚合。
- 对每个真实库存持仓调用 `predict_for_skin`，以数量加权聚合 D1-D7。
- 30 天线聚合 `trend30d.p50`。
- 无预测的持仓按最新价格持平，避免总资产被低估。
- 预测桥接使用各持仓 `forecastAnchorPrice` 聚合值，实际历史末点不被修改。
- 返回数量覆盖和价值覆盖，前端显示橙色 7 天精确线、绿色 30 天趋势线。

## 一致性

- `portfolio_diagnose` 也通过 `predict_for_skin` 获取 7 天和 30 天结果。
- SHAP 明确标记为 XGBoost 解释，不暗示解释 Hybrid V2。
- 保留旧响应字段作为兼容别名，但新前端只使用双轨字段。
